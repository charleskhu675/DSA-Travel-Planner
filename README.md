## Travel Planner using Dijkstra's Algorithm and Euclidean Distance

Our project implements an efficient travel planning system by modeling major cities as nodes and transit routes as arcs in a weighted graph. 

The program first calculates the distances between each city using the Euclidean distance formula and stores these cities in a vector.

Using Dijkstra's algorithm, our system will systematically calculate the most optimal path between specific locations on the graph with a priority queue. The project will also utilize a stack to reverse the traversal order and output a chronological travel sequence for the user. 

Our goal is to show how common data structures can be used to solve real-life problems like traveling efficiently.
